# Plugin Skill Builder

Plugin Skill Builder creates ChatGPT-ready skills-only plugin packages from reusable workflows.

Use it when the workflow should become a reusable Skill instead of an MCP server.

## Test Prompt

```text
Create a skills-only plugin from this workflow: review a user request, decide whether MCP is needed, write a focused SKILL.md, validate the package, and prepare a ZIP.
```
